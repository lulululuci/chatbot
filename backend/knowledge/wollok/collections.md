# Colecciones de Wollok

## List

List es una coleccion ordenada de elementos.

Mantiene el orden en el que fueron agregados.

El primer indice es 0.

Una List puede contener elementos repetidos.

### get(index)

Devuelve el elemento ubicado en la posicion indicada.

Ejemplo:

[5, 2, 7].get(0)

Resultado:

5

### first()

Devuelve el primer elemento de una lista.

Ejemplo:

[1, 2, 3].first()

Resultado:

1

### last()

Devuelve el ultimo elemento de una lista.

Ejemplo:

[1, 2, 3].last()

Resultado:

3

### size()

Devuelve la cantidad de elementos.

Ejemplo:

[1, 2, 3].size()

Resultado:

3

## Set

Set es una coleccion que no permite elementos duplicados.
